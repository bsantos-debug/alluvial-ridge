# Independent alluvial ridge reconstruction

Work in progress: independent reconstruction of Nicholas et al. (2018),
*Hydrodynamic controls on alluvial ridge construction and avulsion likelihood
in meandering river floodplains*, doi:10.1130/G40104.1.

The intended deliverable is a C++ coupled channel–floodplain model, saved
numerical output, independent plots of every manuscript panel, and a LaTeX/PDF
report with a panel-level assessment. No panel is reproduced yet.

Only published written scientific descriptions are specifications. Original
model code, output files, plotting scripts, source data, and figure files are
excluded. Published figures may be inspected for comparison, never digitized.
Locally downloaded papers are ignored by git and are not simulation inputs.
The published result columns in DR2 must not be used as model inputs or as
replacement plot data. Configuration values in DR2 are permitted specifications.

See docs/specification.md for documented parameters and unresolved choices,
docs/panels.csv for the complete panel ledger, and docs/progress.md for current
state. The supplied AGENTS.md and academic style guide govern this project.
